# ADR-0005 — الوثائق جزء من تعريف المنجز وتُفحص آلياً

- **الحالة:** مقبول — 2026-09-04
- **السياق:** المتطلبات كانت متناثرة في 4 مستودعات وتوثيق V2 تأخر عن الكود؛ المستخدم اشترط تحديث التوثيق مع كل تغيير.
- **القرار:** سياسة `docs/50-quality/02-DOCUMENTATION-POLICY.md` + سكربت `check-docs` في CI + قالب PR بخانة الوثائق + HANDOFF لكل جلسة + CHANGELOG لكل PR.
- **العواقب:** PR بلا وثائق يفشل في CI.
