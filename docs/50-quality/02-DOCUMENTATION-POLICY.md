# سياسة التوثيق (Documentation Policy)

> مطلب المستخدم: "أي تحديث يكون يتحدث التوثيق". هذه السياسة إلزامية وتُفحص في كل PR.

## 1. خريطة الوثائق ومالك التحديث

| المجلد | الغرض | يُحدَّث عند |
|---|---|---|
| `docs/00-analysis/` | التحليل التاريخي للنسخ السابقة | نادراً (اكتشاف جديد في المرجعيات) |
| `docs/10-research/` | البحوث والمعايير | تغيّر معيار/تشريع أو بحث جديد |
| `docs/20-product/01-REQUIREMENTS.md` | المتطلبات وحالتها | **كل PR** يغيّر حالة متطلب |
| `docs/20-product/02-PERMISSIONS-MATRIX.md` | الصلاحيات | أي إضافة/تغيير صلاحية |
| `docs/20-product/03-USE-CASES.md` | التدفقات | تدفق جديد/معدَّل |
| `docs/30-architecture/*` | المعمارية، النموذج، العقد، الواجهة | أي migration، action جديدة، مكوّن layout |
| `docs/40-plan/01-ROADMAP.md` | حالة المهام | **كل PR** |
| `docs/50-quality/*` | DoD، الاختبار، هذه السياسة | تغيّر العملية |
| `docs/60-adr/` | قرارات معمارية | قرار جديد (ملف جديد، لا يُعدَّل القديم بل يُلغى بـ Superseded) |
| `docs/90-handoff/HANDOFF.md` | حالة التشغيل، الدخول، المشاكل المعروفة، آخر ما تم | **كل جلسة عمل** |
| `CHANGELOG.md` | Keep a Changelog | **كل PR** تحت `[Unreleased]` |
| `README.md` | مدخل المشروع | تغيّر التشغيل/الستاك |

## 2. قواعد

1. **وثيقة في نفس الـ PR** — لا PR "توثيق لاحق".
2. **المعرّفات ثابتة:** `FR-*`, `NFR-*`, `GAP-*`, `UC-*`, `Pn-xx`, `ADR-nnnn`, `SEC-*`, `BUG-*`. لا يُعاد استخدام معرّف محذوف.
3. **الحالة بثلاث رموز:** `☐` لم يُبدأ · `◐` جزئي · `☑` منجز ومُختبَر.
4. **كل وثيقة تبدأ بسطر غرض** وتُذكر فيها المصادر.
5. **اللغة:** عربية للنص، إنجليزية للأكواد والمعرّفات والمصطلحات التقنية.
6. **الأمثلة البرمجية في الوثائق** يجب أن تطابق الكود الفعلي؛ عند الاختلاف الكود هو الحقيقة والوثيقة تُصحَّح.
7. **لا أسرار في الوثائق** (درس `SCAM/HANDOVER.md`). بيانات الدخول التجريبية فقط مع تحذير.
8. **ADR** بصيغة: السياق → القرار → البدائل → العواقب → الحالة.
9. **CHANGELOG** بأقسام: Added / Changed / Fixed / Security / Docs / Removed، مع إشارة `(FR-xxx, Pn-xx)`.
10. **قالب PR** (`.github/PULL_REQUEST_TEMPLATE.md`) يحوي قائمة تحقق DoD وخانة "الوثائق المحدّثة".

## 3. فحص آلي (يُضاف في P0-16)

سكربت `scripts/check-docs.ts` في CI:
- يفشل إذا تغيّر `schema.prisma` دون تغيير `02-DATA-MODEL.md`.
- يفشل إذا تغيّر `permissions.ts` دون `02-PERMISSIONS-MATRIX.md`.
- يفشل إذا أُضيف `actions.ts` أو دالة مُصدَّرة جديدة دون `04-API-CONTRACT.md`.
- يفشل إذا لم يتغيّر `CHANGELOG.md` في PR يلمس `app/src`.
- يحذّر إذا لم يتغيّر `HANDOFF.md` خلال آخر 3 PRs.
